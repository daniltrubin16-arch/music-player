# Музыкальный плеер для Android

Плеер для музыки с устройства: библиотека, плейлисты, мини-плеер с перемоткой,
перемешивание и повтор, управление из уведомления (работает в фоне).

**Стек:** Kotlin, Jetpack Compose (Material 3), Room, MediaPlayer. Android 8.0+ (API 26).

## Что умеет

- Показывает всю музыку из памяти телефона (запрашивает доступ к аудио).
- Плейлисты: создать, переименовать, удалить, добавить трек (меню ⋮ у трека), убрать трек.
- Воспроизведение плейлиста по порядку или вперемешку.
- Мини-плеер: пауза/плей, следующий/предыдущий, перемотка, shuffle, повтор.
- Уведомление с кнопками, музыка играет при свёрнутом приложении.
- Сортировка по дате добавления в библиотеке и в плейлистах.
- Вкладка «Рекомендации»: новые исполнители, похожие на вашу музыку (Deezer API, без ключа). Играют 30-секундные превью; нужен интернет.

## Как получить APK

### Вариант 1. Android Studio

1. Установите [Android Studio](https://developer.android.com/studio).
2. `File → Open` и выберите папку `MusicPlayer`. Дождитесь синхронизации Gradle.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. Сборка в облаке (GitHub Actions)

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions → Build APK** (запускается при пуше в `main`/`master`
   или кнопкой **Run workflow**).
3. После окончания сборки скачайте `MusicPlayer-debug-apk` из раздела **Artifacts** и
   распакуйте zip — внутри `app-debug.apk`.

## Установка на телефон

1. Перенесите `app-debug.apk` на телефон.
2. Откройте файл и разрешите установку из этого источника, если система спросит.
3. При первом запуске разрешите доступ к аудио и (на Android 13+) уведомления.

APK подписан отладочным ключом, этого достаточно для личной установки.
Для публикации в Google Play понадобится release-сборка со своим ключом.
